# Recursos históricos de FRONTLINE 1944

Este directorio documenta el paquete gráfico histórico preparado para la campaña de 1938.

- Imágenes catalogadas: **56**
- Categorías: **6**
- Logo oficial original: https://drive.google.com/file/d/11IC6sL7whibIwO1i5U5onHRdzq1Af4xc/view
- Pack fuente ZIP: https://drive.google.com/file/d/1IKWmC_sjXO_YuiO7Oo_XxVg2WhZib37a/view
- Carpeta maestra: https://drive.google.com/drive/folders/14h4XjGlsnxZmcsioKzSuuLVUGYq7IlAr

`manifest.json` conserva nombre, categoría, MIME, tamaño, ID y vínculo de procedencia de cada una de las 56 imágenes para que el material permanezca trazable y pueda integrarse por escena sin perder contexto histórico.
